# Stramont

Plataforma de **guías de estudio visuales** que convierten los temas más confusos
de la carrera en algo que hasta un niño de 9 años entiende.

## Método

Cada idea se presenta como una "ficha" con tres niveles:

- **Teclado** (índice): color + número + nombre corto.
- **Monitor**: el significado explicado de forma muy simple.
- **Altavoces**: una imagen/emoji para memorizar.

Las fichas siguen un semáforo de colores (amarillo → azul → rojo) como ritmo de memoria.

## Contenido

- `index.html` — página principal (método + catálogo + apoyo).
- `segmentacion-de-mercados.html` — guía interactiva de Segmentación de Mercados.
- `segmentacion-de-mercados.pdf` — versión imprimible/descargable.
- `estilos.css` — identidad visual.
